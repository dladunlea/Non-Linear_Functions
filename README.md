# Non-Linear Functions

Step-by-step practice apps for CP2U5 (quadratics, exponential equations, rational equations, and the concert income/profit problems).

Open `index.html` for the list of apps. Each app is a single self-contained HTML page:

1. special-products.html
2. trinomials.html
3. sketching-parabolas.html
4. equations-from-intercepts.html
5. exponential-equations.html
6. rational-equations.html
7. cost-and-income.html
8. concert-profit.html

Progress is saved in each student's browser (localStorage). Nothing is sent anywhere.
